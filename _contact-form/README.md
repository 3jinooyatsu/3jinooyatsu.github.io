# お問い合わせフォームの受け口（Google Apps Script）

サイトのお問い合わせフォーム（開発・採用・会社）から送られた内容を、次の3か所に届けます。

- **Google スプレッドシート**：フォームごとのシート（「開発のご相談」「採用」「会社へのお問い合わせ」）に1行ずつ記録します。左端の「対応状況」はチームで書き換えて使えます。
- **メール**：info@3jino-oyatsu.com に届きます。そのメールに返信すると、問い合わせた人に届きます。
- **Slack**：指定したチャンネルに通知します。

このフォルダ（`_contact-form/`）はサイトには公開されません。名前が `_` で始まるフォルダは、GitHub Pages が公開から外します。

---

## 1. 記録用のスプレッドシートを作る

1. 会社の Google アカウントでログインします。通知メールは、このアカウントから送られます。info@3jino-oyatsu.com を受け取っているアカウントがおすすめです。
2. https://sheets.new を開き、新しいスプレッドシートを作ります。
3. 左上の名前を「サイトのお問い合わせ」などに変えます。

シートは、最初の問い合わせが届いたときに自動でできます。

## 2. Apps Script にコードを貼る

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開きます。
2. 左上の「無題のプロジェクト」を「お問い合わせフォーム」に変えます。
3. 「コード.gs」の中身をすべて消し、このフォルダの [Code.gs](Code.gs) の内容をすべて貼り付けます。
4. 保存します（⌘S）。

## 3. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」を開きます。
2. 「種類の選択」の歯車から「ウェブアプリ」を選びます。
3. 次のように設定します。

   | 項目 | 設定 |
   |---|---|
   | 説明 | お問い合わせフォーム |
   | 次のユーザーとして実行 | 自分 |
   | アクセスできるユーザー | **全員** |

4. 「デプロイ」を押し、「アクセスを承認」からアカウントを選んで「許可」します。
   - 「このアプリは Google で確認されていません」と出た場合は、自分で作ったものなので「詳細」→「（プロジェクト名）に移動」で進めて大丈夫です。
   - 「アクセスできるユーザー」に「全員」が出ない場合は、Google Workspace の管理者が外部への公開を制限しています。管理コンソールの設定変更が必要です。
5. 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）をコピーします。
6. その URL をブラウザで開き、`{"ok":true,…}` と表示されれば公開できています。

URL をサイトに設定すると、フォームがこの受け口に送るようになります。設定場所は `contact/index.html` の `data-contact-endpoint` です。

## 4. Slack に通知する

1. https://api.slack.com/apps を開き、「Create New App」→「From scratch」を選びます。
2. App Name に「サイトのお問い合わせ」と入れ、通知先のワークスペースを選びます。
3. 左のメニューから「Incoming Webhooks」を開き、「Activate Incoming Webhooks」をオンにします。
4. 下の「Add New Webhook」を押し、通知先のチャンネルを選んで「許可する」を押します。
   - ワークスペースの設定によっては、Slack の管理者の承認が必要です。
5. 発行された Webhook URL（`https://hooks.slack.com/services/…`）をコピーします。
   - **この URL は鍵と同じです。** 知っている人は誰でもそのチャンネルに投稿できるので、チャットやサイトには貼らないでください。
6. Apps Script に戻り、左の歯車「プロジェクトの設定」の一番下にある「スクリプト プロパティを追加」を押します。
7. プロパティに `SLACK_WEBHOOK_URL`、値にコピーした URL を入れて保存します。

スクリプト プロパティは保存した時点で反映されます。デプロイし直す必要はありません。

---

## あとから変えたいとき

スクリプト プロパティで変えられます。変更はすぐ反映され、デプロイし直す必要はありません。

| プロパティ | 内容 |
|---|---|
| `MAIL_TO` | 通知メールの宛先。ないときは info@3jino-oyatsu.com |
| `MAIL_TO_RECRUIT` | 採用だけ別の宛先にするとき。開発は `_DEVELOPMENT`、会社は `_COMPANY` |
| `SLACK_WEBHOOK_URL_RECRUIT` | 採用だけ別のチャンネルに通知するとき。開発は `_DEVELOPMENT`、会社は `_COMPANY` |

**コード（Code.gs）を変えたとき**は、公開中のものを新しい版に差し替えます。

1. 「デプロイ」→「デプロイを管理」を開き、鉛筆マークを押します。
2. 「バージョン」で「新バージョン」を選び、「デプロイ」を押します。

URL は変わらないので、サイト側の変更はいりません。

## しくみの補足

- 人には見えない入力欄が埋まっている送信は、自動送信とみなして捨てます。
- 10分間に30件を超えたときは、受け付けを一時的に止めます。
- 送信に失敗したときは、サイトに「メールアプリから送信」のリンクを出します。
- スプレッドシートや Slack への送信に失敗しても、メールが届けば受け付けとします。失敗の記録は、Apps Script の「実行数」で見られます。
