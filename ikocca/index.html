いこっか。

集めて、まとめて、でかける。

「ここ行ってみたい」を、思いついたその瞬間に。
ふたりで、グループで、ひとりで。
行きたい場所を集めて、次のおでかけを決められる iOS アプリです。

iOS 17.6 以降・無料（アプリ内課金あり）

アプリの画面

How it works

使い方

  1. 01集める

    SNS の投稿も地図のリンクも、シェアするだけ。AI が場所を読み取って一行で追加。

  2. 02まとめる

    「週末の京都」「鎌倉デート候補」など、用途別のまとめに自由に束ねる。

  3. 03計画する

    日付を決めたら旅のしおりへ。Day ごとに割り振り、地図で当日の動きもひと目。

  4. 04残す

    行ったら「いったよ」へ。思い出写真と一言メモを添えて、制覇マップに刻む。

Features

主な機能

  • Collect

    SNS シェアで、そのまま追加

    Instagram・TikTok・X の投稿を共有するだけ。AI がキャプションから店名・エリア・ジャンルを読み取って登録します。

  • Map

    地図リンクもワンタップ

    Google マップ / Apple マップ / NAVER（韓国）の URL を貼るだけで、名前も位置も自動で入力されます。

  • Together

    ふたり・グループでリアルタイム共有

    招待コードで招くだけ。追加も編集もその場で同期し、誰が言い出したかも一目でわかります。

  • Discover

    眺めて見つけるホーム

    今月・気分・エリア・ジャンル・季節……横スクロールの棚で次の行き先が自然と目に入る。今日の天気もひと目で。

  • Publish

    まとめをリンクで共有

    作ったまとめは公開リンクに。アプリを持っていない友だちにも、ブラウザでそのまま送れます。

  • Revisit

    制覇マップ＆ウィジェット

    行った場所を地図のピンで可視化（X / 47 都道府県）。ホーム画面ウィジェットには、次の「行きたい」と天気を添えて。
