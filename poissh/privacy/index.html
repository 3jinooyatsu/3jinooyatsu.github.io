プライバシーポリシー

３時のおやつ合同会社（以下「当社」といいます）は、当社が提供する iOS アプリ「ポイッシュ」（以下「本アプリ」といいます）における、利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

1. 基本方針

本アプリは、アカウント登録を必要としません。利用者が登録したカード・設定・利用履歴は、すべて利用者の端末の中だけに保存されます。当社がこれらを受け取ることはなく、閲覧することもできません。本アプリを削除すると、これらの情報も端末から削除されます。

2. 端末内にのみ保存される情報

  • 登録したカード：名称、色、どのアプリを開くかの設定。
  • 利用の記録：どのカードをいつ提示したかの回数と日時。ホームの並び順を決めるためにのみ使用します。
  • 各種設定：通知のオン／オフ、お店のジャンルの並び順、共通ポイントを出すアプリの選択など。

これらは端末の外に送信されません。

3. 位置情報の取り扱い

本アプリは、近くのお店をホームの上部に表示すること、および登録したお店に近づいた際に通知することのみを目的として、位置情報を利用します。

  • 現在地を保存しません。当社に送信することもありません。
  • 周辺に対象の店舗があるかを調べるため、検索する範囲を Apple の地図（MapKit / MKLocalSearch）に問い合わせます。この通信は Apple Inc. に対して行われ、同社のプライバシーポリシーに従います。
  • 位置情報の許可は、iOS の「設定」からいつでも取り消せます。取り消した場合、近くのお店の表示と到着時の通知のみが停止します。

4. 当社に届く唯一の情報（アプリ追加のリクエスト）

本アプリには、一覧にないアプリの追加を依頼する機能があります。利用者がこの機能を実行した場合に限り、以下の情報が当社に送信されます。

  • 選択されたアプリの名称、App Store の ID、バンドル ID
  • そのアプリを探すために入力された語句
  • 本アプリのバージョン

端末または利用者を識別する情報は送信しておらず、当社も保持していません。通信の性質上、IP アドレスが配信事業者（Cloudflare, Inc.）のログに一時的に記録されますが、当社がこれをリクエスト内容と結びつけて保存することはありません。受け取った内容は、本アプリの一覧に追加するアプリを検討する目的にのみ使用します。

5. 第三者サービスの利用

  • Apple サービス（Apple Inc.）：地図検索、ローカル通知、ウィジェット表示、App Store からの配信などに OS の機能を利用します。
  • GitHub Pages（GitHub, Inc.）：本アプリが表示するアプリ一覧（カタログ）の配信に利用します。配信は取得のみで、端末から情報を送信しません。
  • Cloudflare Workers（Cloudflare, Inc.）：第 4 項のリクエストの受け取りに利用します。

6. 広告・トラッキング

本アプリは、広告を配信しません。広告のための情報収集、および App Tracking Transparency（ATT）に基づく他社アプリ・サイトを横断したトラッキングを行いません。第三者の広告 SDK および解析 SDK も導入していません。

7. 他社の名称およびアイコンについて

本アプリに表示される各社の名称およびアイコンは、App Store で公開されている情報をもとに表示しているものであり、各社の商標です。本アプリは各社とは独立したものであり、ポイントの付与・残高の管理は、それぞれの公式アプリにおいて行われます。

8. 子どもの利用

本アプリは、年齢を尋ねる項目を持たず、個人を特定する情報を取得していません。

9. ポリシーの改定

当社は、法令の改正、サービス内容の変更等に応じて、本ポリシーを改定することがあります。改定後の内容は、本ページに掲載した時点から効力を生じます。

10. お問い合わせ窓口
