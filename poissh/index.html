ポイッシュ

探さずに、シュッと出す。

レジの前で「どのアプリだっけ」と探す時間を、なくすためのアプリ。
共通ポイントはいつも同じ場所に。
お店のアプリは、近づくと一番上に出ます。

iOS 17.0 以降・無料（アプリ内課金なし・広告なし）

How it works

使い方

  1. 01選ぶ

    最初に、使うアプリを選ぶだけ。役割の設定も、お店の場所の登録も必要ありません。

  2. 02近づく

    お店の近くに来ると、そのお店のアプリがホームの一番上に出ます。どの店舗かは、その時の現在地から自動で判断します。

  3. 03出す

    タップすると、画面を挟まずにそのアプリが開きます。戻ってもう一度開けば、共通ポイントが決まった場所に並んでいます。

  4. 04知らせる

    通知をオンにすると、お店に着いた時に「ここで何が貯まるか」をロック画面でお知らせします。うるさければ、その通知から止められます。

Features

主な機能

  • Fixed

    共通ポイントは、いつも同じ場所

    楽天ポイント・d ポイント・Ponta・V ポイントなどは、ホームの決まった位置に固定で並びます。順番が変わらないので、店員さんに聞かれてから探す必要がありません。

  • Nearby

    近くのお店が、一番上に

    使用頻度・直近の利用・時間帯・曜日から、いま出しそうなものを予測します。圏内のお店があれば最優先で表示します。

  • Map

    お店の場所は、地図から自動で

    お店の場所を登録する必要はありません。チェーン名から周辺の店舗を地図で調べるので、出先の同じチェーンでも同じように動きます。

  • Notify

    着いたらロック画面でお知らせ

    登録したお店に着くと、そこで貯まるポイントを通知します。持っているカードのうち、実際に出せるものだけを表示します。

  • Genre

    ジャンルで並び、順番も変えられる

    コンビニ・カフェ・ドラッグストアなど、日本のお店をジャンルごとにまとめて表示します。よく行くジャンルは自分で上に動かせます。

  • Local

    アカウント不要。端末の中だけ

    会員登録もログインもありません。登録した内容は端末の中だけに保存され、現在地が保存されることもありません。
